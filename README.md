## Overview

Factorio Bob's Mods Planner is a production planning tool specifically designed for the massively expanded intermediate product chains introduced by Bob's Mods, helping players calculate how many assemblers are needed for target throughputs through Bob's complex multi-stage ore, chemical, and electronic component chains.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Bobs Mods Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Chain Calculator** | Calculates assembler counts for complete Bob's Mods production chains |
| **Multi-Stage Support** | Handles Bob's 4+ stage intermediate product chains accurately |
| **Ratio Display** | Shows optimal assembler ratios between production stages |
| **Bottleneck Finder** | Identifies the bottleneck stage limiting overall production output |
